# 双脉冲控制系统 · 潜在问题清单

> 逐行注释过程中发现的隐患，按严重程度排序。每条注明位置与后果。
> 标注：🔴 真 BUG（会产生错误行为）｜🟡 隐患（特定条件下出问题）｜⚪ 瑕疵（不影响功能）

---

## 🔴 1. 通道轮换掩码写错，特定勾选组合下通道永远切换不到（示波器库）

- **位置**：`OscilloscopeClassLibrary/TcpTranslateClass.cs`，`HandleIncomingData` 中 `Chnumber == 3`（CH4）分支
- **代码**：`else if ((CHANNum & 0x03) == 0x03)` → 应为 `(CHANNum & 0x04)`
- **后果**：只勾选 **CH3+CH4** 两个通道时，读完 CH4 后无法轮换到 CH3，CH4 被反复读取，CH3 永远读不到。
- **建议**：改为 `0x04`。改完建议把四个分支的轮换逻辑抽成一个公共方法，消除四份重复代码（重复代码是这类笔误的温床）。

## 🔴 2. TCP 拆包未处理，波形报文可能被静默丢弃（示波器库）

- **位置**：`OscilloscopeClassLibrary/TcpTranslateClass.cs`，`HandleIncomingData`
- **问题**：`new byte[_client.Available]` 假设"一次 Read 能收到完整报文"。TCP 不保证这一点：
  - 1000 点报文若被拆成两包 → 前包段数 < 1000，被静默丢弃，**波形丢帧**；
  - 两条单值回答若粘在一包 → 段数 = 2，两种判断都不命中，**状态机卡死**（无超时恢复）。
- **对照**：电压源库的 `ProcessValueData` 用累积缓冲区 `mRecvBuffer` 拼帧，是正确的做法。
- **建议**：给示波器库加同款累积缓冲 + 按"段数≥1000 且以换行结尾"判定完整报文；问答链条加超时（如 2 秒无响应重置 ExpectQuery）。

## 🔴 3. 连接失败也显示"已连接"（三个通信类同病）

- **位置**：三个 `TcpTranslateClass.ConnectAsync` 的 catch 块
- **代码**：`reciveState("…通信建立失败…", 编号, true)` —— Connectflag 传了 `true`
- **后果**：仪器没连上（IP 错、没开机），界面状态栏照样显示"已连接"，误导排障。
- **建议**：三处 catch 里的 `true` 全部改 `false`。

## 🟡 4. 问答链条一旦卡住，取数永久停止（示波器库）

- **位置**：`OscilloscopeClass.ThisEquitRequestTime_Event` + `TcpTranslateClass`
- **机制**：定时器发问后置 `EquipDataRead = false`，只有收到波形数据才置回 `true`。
- **后果**：链条中任何一环的回答丢失（见问题 2），`EquipDataRead` 永远回不来 → **启动刷新后再无数据**，只能重启软件。
- **建议**：定时器里加"卡死检测"：若超过 2 秒未收到数据，强制重置 `EquipDataRead = true` 并 `ExpectQuery = 0`。

## 🟡 5. 运行中断线无任何重连（三个通信类同病）

- **位置**：三个 `HandleIncomingData` 的退出路径
- **后果**：网线被拔、仪器重启后，接收线程异常退出 → 软件必须重启才能恢复连接。注释掉的 `bytesRead == 0 → Close` 断线检测也从未启用。
- **建议**：长期改进项——接收线程退出后触发重连流程。

## 🟡 6. `Process.Kill()` 强杀退出（主程序）

- **位置**：`MainWindow.Image_MouseDown`（退出按钮）
- **后果**：不保存的 Excel、未关闭的 TCP 连接全被硬断；仪器可能停留在带电输出状态（虽有 `:OUTP1 OFF`，但只对信号源发了，两台电压源没关）。
- **建议**：改为正常关闭流程：关各仪器输出 → 关 TCP → `Application.Current.Shutdown()`。

## 🟡 7. 信号源电压设置的整数除法 + 无范围校验

- **位置**：`SignalClass.ValueSet(byte Value)`，`Value/2` 是整数除法（5→2）
- **后果**：电压与偏移失配；byte 上限 255，输入超界直接溢出异常。
- **建议**：参数改 float，`(Value/2f)`。

## 🟡 8. 死代码里的越界索引

- **位置**：`MainWindow.SomeMethod()`（未被调用的测试方法）
- **代码**：`WriteDataGroupCh1[0, i] = i` —— 数组第一维长度 1000，但按 `[0, i]` 用第二维索引，i 到 999 时第二维越界。
- **建议**：该方法已无用处，建议直接删除（连同随机数测试逻辑）。
