# 双脉冲控制系统 · 代码逻辑思维导图

> 与 `代码逻辑思维导图.png` 配套的文字版，便于检索。

```
双脉冲控制系统
│
├─ 界面层 MainSoftwareV100
│   ├─ MainWindow.xaml(.cs) —— 主窗口、全部按钮事件、保存逻辑（含 2026-10 新增的保存弹窗）
│   ├─ ConnectInit —— 连接弹窗（填四台仪器的 IP+端口）
│   ├─ MainViewModel —— OxyPlot 绘图模型（CH1~CH4 四条曲线、横纵轴）
│   ├─ PlotSeriesViewModel1 —— 曲线显隐勾选框的数据绑定
│   └─ MyControl —— 自定义控件（Led、NumericUpDown、NumberBox、MyTime）
│
├─ 驱动层（三个类库，每台仪器一个）
│   ├─ OscilloscopeClassLibrary —— 示波器 · SCPI 文本协议
│   │   ├─ OscilloscopeClass —— 指令翻译 + 1秒定时器调度
│   │   └─ TcpTranslateClass —— TCP收发、报文解析(按逗号切段)、状态机、委托回调
│   ├─ SingalClassLibrary —— 信号源 · SCPI（只发不收，接收线程为空壳）
│   │   ├─ SignalClass —— 波形生成(正弦/方波/自定义脉冲)、下载、触发
│   │   └─ TcpTranslateClass —— 发送 + 连接（接收未实现）
│   └─ ValueSourceN2410ClassLibrary —— 两台电压源 · Modbus-RTU 二进制协议
│       ├─ N2410Class —— N2410（地址1）：电压/电流/保护/通道/开关设置 + 200ms查询
│       ├─ N36200Class —— N36200（地址2）：同上，寄存器映射不同
│       ├─ PublicToolClass —— CRC16校验（查表法）+ float↔大端字节
│       └─ TcpTranslateClass —— TCP收发 + 拼帧解析（累积缓冲 mRecvBuffer，13字节/帧）
│
├─ 核心数据流（示波器取数链，1秒一轮）
│   ① 1秒定时器 → 按 CHANNum 位掩码选当前通道
│   ② 发 :WAVeform:XINCrement?（ExpectQuery=1）
│   ③ 收到增量 → 发 :WAVeform:XORigin?（ExpectQuery=2）
│   ④ 收到原点 → 发 :WAVeform:DATA?（仪器回 1000 个 ASCII 电压值）
│   ⑤ 接收线程解析 → 回调 SomeActMethod（主程序）
│   ⑥ 真实时间 = XORigin + 序号 × XINCrement → 刷新图表 + 写 Excel 缓存
│
└─ 支撑机制（贯穿全局）
    ├─ 委托回调 ×2
    │   ├─ reciveState(内容, 仪器编号, 状态) → 写日志 + 更新底部状态栏
    │   └─ thisNetPublicTool(数据, 通道, 时间参数) → 刷新曲线 / 电压电流显示
    └─ 日志系统 → exe目录\Logs\log_日期.txt（连接事件、异常均落盘）

协议对比：
  示波器/信号源 = SCPI 文本指令（问句带 ?，回答为逗号分隔的 ASCII）
  电压源       = Modbus-RTU 二进制帧（地址+功能码+寄存器+数据+CRC16 校验，查表法生成）
```
